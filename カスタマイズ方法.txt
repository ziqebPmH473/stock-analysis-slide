====================================================
  株価分析 スライド生成ツール カスタマイズ方法
====================================================

index.html をテキストエディタ（メモ帳、VSCode 等）で開いて編集してください。
変更箇所はすべて <style> タグ内の CSS です（ファイル上部の方にあります）。
変更後はブラウザをリロードし、テキストを再貼り付けするとプレビューに反映されます。

====================================================
【スライド共通】
====================================================

----------------------------------------------------
【共通-1】各スライドのタイトル文字サイズ
----------------------------------------------------
スライド1〜5のタイトルはそれぞれ個別クラスで管理されています。

  スライド1 タイトルなし（銘柄名がタイトル相当）
  スライド2: .s2-title  { font-size: 36px; }  ← ここを変更
  スライド3: .s3-title  { font-size: 28px; }  ← ここを変更
  スライド4: .s4-title  { font-size: 36px; }  ← ここを変更
  スライド5: .s5-title  { font-size: 36px; }  ← ここを変更

----------------------------------------------------
【共通-2】各スライドの外側余白（上下・左右パディング）
----------------------------------------------------
  スライド1: .s1-wrap { padding: 24px 64px 22px; }
  スライド2: .s2-wrap { padding: 44px 72px 40px; }
  スライド3: .s3-wrap { padding: 44px 72px 40px; }
  スライド4: .s4-wrap { padding: 44px 72px; }      ← 上下 44px / 左右 72px
  スライド5: .s5-wrap { padding: 44px 72px; }      ← 上下 44px / 左右 72px

  値を大きくする → 余白が増える（内容が小さく見える）
  値を小さくする → 余白が減る（内容を広く使える）

----------------------------------------------------
【共通-3】タイトルと本文（コンテンツ）の間隔
----------------------------------------------------
各スライドのラッパーが flex コンテナで、gap がタイトル〜本文間の余白です。

  スライド4: .s4-wrap { gap: 16px; }   ← タイトル〜カードリスト間
  スライド5: .s5-wrap { gap: 36px; }   ← タイトル〜リスク本文間

  値を大きくする → タイトルと本文の間が広がる
  値を小さくする → 間が詰まる


====================================================
【スライド1: 現状の整理】
====================================================

----------------------------------------------------
【S1-1】銘柄名のフォントサイズ
----------------------------------------------------
  .s1-name { font-size: 28px; }   ← ここを変更

  銘柄名が長い場合は小さくする（例: 20px）
  短い場合は大きくする（例: 32px）

----------------------------------------------------
【S1-2】現在株価のフォントサイズ
----------------------------------------------------
  ⚠ CSS の .s1-price を変更しても効きません。
    株価のフォントサイズは JavaScript のインラインスタイルで制御されています。

  変更するには <script> タグ内で以下の行を検索してください:
    検索キー: s.length>9?'28px'

  該当箇所（1行）:
    return s.length>9?'28px':s.length>7?'32px':'40px';

  意味:
    文字数 10以上 → 28px（例: 1,234,567円）
    文字数  8〜9  → 32px（例: 100,000円）
    文字数  7以下 → 40px（例: 9,215円） ← デフォルト

  例）デフォルトを 36px にしたい場合:
    return s.length>9?'28px':s.length>7?'32px':'36px';
                                                  ↑ここを変更

----------------------------------------------------
【S1-3】変動要因・強み・弱みの文字サイズ
----------------------------------------------------
  .s1-factor    { font-size: 17px; }   ← 変動要因の各行
  .s1-sw-item   { font-size: 15px; }   ← 強み・弱みの各行

----------------------------------------------------
【S1-4】各カードの上下余白（カード内パディング）
----------------------------------------------------
  .s1-factors-card { padding: 10px 16px 8px; }   ← 変動要因カード
  .s1-s-card       { padding: 10px 16px 8px; }   ← 強みカード
  .s1-w-card       { padding: 10px 16px 8px; }   ← 弱みカード

【スライド2: 短期株価レンジ予測】
====================================================

----------------------------------------------------
【S2-1】シナリオ行のフォントサイズ

----------------------------------------------------
【S2-2】シナリオ行の間隔
----------------------------------------------------

====================================================
【スライド3: 12ヶ月後シナリオ】
====================================================

----------------------------------------------------
【S3-1】テーブルの文字サイズ
----------------------------------------------------
  .s3-table td  { font-size: 17px; }   ← セルのテキスト全般
  .s3-pc        { font-size: 24px; }   ← 目標価格（大きい数値）
  .s3-table th  { font-size: 14px; }   ← ヘッダー行

----------------------------------------------------
【S3-2】テーブルのセル余白
----------------------------------------------------
  .s3-table td { padding: 13px 16px; }   ← 上下 13px / 左右 16px
  値を小さくする → 行の高さが詰まる（行数が多い場合に有効）


====================================================
【スライド4: 転換点のモノサシ】
====================================================

----------------------------------------------------
【S4-1】カード間の余白
----------------------------------------------------
  .s4-items { gap: 7px; }   ← ここを変更

  値を大きくする → カード間が広がる
  値を小さくする → カード間が詰まる（指標数が多い場合に有効）

----------------------------------------------------
【S4-2】カード内：指標名と値・ゲージの間隔
----------------------------------------------------
  .s4-item-head { margin-bottom: 4px; }   ← ここを変更

  値を大きくする → 指標名とゲージバーの間が広がる
  値を小さくする → 詰まる

----------------------------------------------------
【S4-3】指標名のフォントサイズ
----------------------------------------------------
  .s4-iname { font-size: 20px; }   ← ここを変更

----------------------------------------------------
【S4-4】現在値・目安値の文字サイズ
----------------------------------------------------
  .s4-ivals { font-size: 17px; }              ← 「現在 〇〇 → 目安 〇〇」の行
  .s4-icur  { color: #0f172a; }             ← 現在値の色（黒）
  .s4-itgt  { color: #2563eb; }             ← 目安値の色（青）

----------------------------------------------------
【S4-5】補足説明のフォントサイズ
----------------------------------------------------
  .s4-inote { font-size: 15px; }   ← ここを変更

----------------------------------------------------
【S4-6】デュアル閾値カードの文字サイズ（2つの判断基準がある指標）
----------------------------------------------------
  .s4-dual-pos { font-size: 15px; }   ← ↑ 高い閾値行（緑）
  .s4-dual-neg { font-size: 15px; }   ← ↓ 低い閾値行（赤）

====================================================
【参考：CSS の探し方】
====================================================

テキストエディタの「検索」機能（Ctrl+F）でクラス名を検索すると
該当箇所にジャンプできます。

例）「.s4-items」で検索 → gap の値が見つかります

変更後は必ずブラウザをリロードしてプレビューで確認してください。
PNG 出力で最終確認するとより正確です。
